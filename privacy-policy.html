Privacy Policy

LocalBox2FA · Last updated: August 2026

TL;DR: Your 2FA secrets are generated and stored entirely on your device and are never transmitted anywhere. The only network communication is the optional Premium license activation: when you enter a license key, a minimal device identifier and your license key are sent to the license server to verify it. If you never activate a license, the extension never makes a network request.

1. What Stays on Your Device

All TOTP code generation happens locally using your browser's Web Crypto API (HMAC-SHA1). Your saved secret keys are stored in your browser's localStorage and never leave your device. We do not use cookies, analytics, or tracking of any kind, and we do not access your browsing activity.

2. License Activation

Premium features (export and clear-all) are unlocked with an optional license key. Only when you enter a license key and click Activate does the extension contact the license server at api.annmax1983.com and transmit:

  • License key — the key you entered
  • Device ID — a one-way hash derived from non-identifying device characteristics (operating system, CPU core count, device memory, touch support, screen color depth). It cannot be reversed to identify you.
  • Browser metadata — browser name/version, language, and timezone

This is the only network communication the extension performs, and it happens only when you activate a license. If you have no license, all features available to you work completely offline and nothing is ever sent.

3. How It Works

  • Input — You enter a TOTP secret key directly in the extension popup
  • Processing — TOTP codes are generated using the Web Crypto API (HMAC-SHA1) entirely in your browser
  • Storage — Saved secrets are stored in your browser's localStorage and never leave your device
  • License state — After activation, your license key and device ID are stored in your browser's extension storage, used only to remember your activation
  • Export — Exported files are saved directly to your local downloads folder

4. Permissions

The extension requests only what it needs:

  • storage — to persist your license status and device ID locally
  • https://api.annmax1983.com/* — to reach the license server during activation only

It does not access your browsing history, tabs, or other website data.

5. Third-Party Services

The license server is operated by the LocalBox2FA developer. No data is shared with any other third party. The extension does not use advertising or analytics services.

6. Data Retention & Removal

License data is stored only in your browser's extension storage. You can remove it at any time by clicking Remove in the extension's Settings, or by uninstalling the extension.

7. Changes

If we make changes to this policy, we will update the "Last updated" date above.
