# LocalBox2FA

[English](../README.md) | 中文 | [Español](README_es.md) | [Deutsch](README_de.md) | [日本語](README_ja.md) | [Français](README_fr.md)

一款轻量级浏览器扩展，在本地生成 TOTP 两步验证码。密钥只在本机生成和使用，没有扩展账号、不需要手机 App，也不经过我们的服务器。如果希望在其他电脑上使用同样的账号，可以选择用你已有的浏览器账号做加密同步。

> Chrome / Edge / Firefox 内核 · Manifest V3 · 本地处理 · 隐私优先

| 📱 **二维码转移** | 点击**显示二维码**后才生成可扫描的二维码，把账号迁移到手机验证器。二维码默认隐藏，避免旁人偷看 |

| 🔁 **修改主密码** | 随时用新主密码重新加密所有已保存密钥；账号保持不变，已开启的同步保险柜也会一并换钥 |
| ⏲️ **空闲自动锁定** | 开启加密后，可选择 1、5 或 15 分钟无操作后锁定（默认 5 分钟）。关闭弹窗始终会从内存中清除密钥 |
| 📤 **导出** | 可导出明文 `.txt` 文件，也可创建用独立密码加密的 `.lb2fa` 备份（备份密码与主密码相互独立） |
| 📥 **导入** | 可从明文文件、加密 `.lb2fa` 备份、`otpauth://` 链接、Google Authenticator 迁移二维码或二维码图片恢复账号；重复和不支持的条目会被跳过 |
| 🌙 **暗色模式** | 跟随系统的深色/浅色偏好 |
| 🌍 **6 种语言** | 英文、中文、日文、西班牙文、德文、法文 |

> 导出（明文或加密）、导入、清空全部和二维码显示**不收费**。备份、恢复、清除和转移自己的密钥属于数据管理，不是付费功能。

## 使用方法

### 生成验证码

1. 点击工具栏中的 LocalBox2FA 图标
2. 在输入框中粘贴 Base32 密钥，或完整的 `otpauth://totp/...` 链接
3. 点击**生成** — 显示验证码和倒计时
4. 点击**复制**把验证码复制到剪贴板

只粘贴 Base32 密钥时使用默认参数（6 位、30 秒、SHA-1）。完整的 `otpauth://` 链接会带上自己的位数、周期和算法，遇到不使用默认参数的服务时需要这种方式。

### 保存账号

1. 生成验证码后点击**保存**
2. 输入名称（如 "GitHub"、"Google"）
3. 账号会出现在列表中，实时显示验证码和倒计时

### 使用已保存的账号

- 点击任意账号即可复制当前验证码
- 列表较长时用搜索框筛选
- 铅笔图标重命名，✕ 图标确认后删除
- 底部的**清空全部**会删除所有已保存记录

### 把账号转移到手机

点击已保存账号上的 ▣ 图标，再点击**显示二维码**。二维码默认不生成，避免在共享屏幕上打开弹窗时被看到。用手机验证器扫码即可导入该账号；离开该对话框后二维码即被清除。

### 加密你的密钥

打开**设置（⚙）→ 主密码**，点击**开启加密**：

1. 设置主密码并确认
2. 已保存的密钥会立即被封存，只有元数据（名称、位数、周期、算法、时间戳和随机记录/设备 ID）保持可读
3. 此后每次打开弹窗，都需要先在锁屏输入密码才会显示验证码

注意：

- 主密码**无法重置或找回**。忘记后只能在锁屏界面清空全部记录重新开始，所以请保留一份导出的备份。
- 派生密钥只存在于内存中，弹窗关闭即销毁 —— 这也是每次都要输密码的原因。
- 每条密文都绑定它所属的记录：把密文挪到另一个账号上无法解密，被篡改的同步副本也就无法让一个熟悉的名称指向别的密钥。
- **关闭加密**会把所有记录解密回明文。只要有任意一条记录无法解密，操作就会被拒绝，并列出受影响的账号，任何数据都不会改变 —— 请先删除这些账号再重试。
- 封存记录在列表中带 🔐 前缀；无法解密的记录也会显示 🔐 而不是验证码。
- **空闲自动锁定**：开启加密后可在**设置 → 安全**中选择**关闭**、**1 分钟**、**5 分钟**（默认）或 **15 分钟**。超过该时长无操作后，保险柜会锁定，敏感对话框关闭，剪贴板也会被清空。

**修改主密码**

打开**设置（⚙）→ 主密码 → 修改主密码**，输入当前密码，再输入两次新密码。本机所有已保存密钥都会重新加密，账号保持不变。若同步已开启，云端副本也会换钥。其他设备随后会报告 Vault 不匹配：输入新密码即可采用云端副本（本机账号会先被清空），或用本机保险柜覆盖云端副本（沿用旧密码）。两种选择都必须由你明确确认，不会自动发生。存在待处理冲突或换钥任务尚未完成时，修改会被拒绝；中断的换钥会在后续同步时重试，完成前不能再次修改主密码。

### 跨设备同步（高级功能）

在同一浏览器账号登录的电脑之间同步已保存的账号。该功能**在你开启之前保持关闭**，需要主密码，并且需要有效授权。

**第一台设备**

1. 打开**设置（⚙）→ 跨设备同步**，点击**开启同步**
2. 查看确认页：会显示将上传多少条账号，以及浏览器厂商能看到什么
3. 确认后，记录会被封存并写入 `storage.sync`

**第二台设备**

1. 让浏览器登录同一账号，并安装 LocalBox2FA
2. 打开**设置 → 跨设备同步 → 加入现有同步**
3. 输入与第一台设备**相同的主密码**

扩展从不同步密码或派生密钥。第二台设备只会收到 Vault 的盐、迭代次数和校验值，用它验证密码，然后用同一密钥封存本地明文记录。密码错误会在任何合并发生前被拒绝。

**合并为什么安全**

- 每条记录都有独立的同步存储键和稳定 ID，删除时留下明确的墓碑 —— 同步键缺失绝不代表"已删除"，一台设备也无法通过写入整个列表抹掉另一台设备的新增
- 覆盖某条记录之前，扩展会重新读取云端最新副本；若另一台设备在此期间修改或删除了它，上传会延后，并把差异作为真正的冲突提示你
- 三方比较（上次同步状态 / 本地 / 远端）会自动应用无冲突的变更
- 如果同一账号确实在两台设备上都被修改，弹窗会让你选择保留**本设备**、**另一台设备**或**两者** —— 未经你的选择，任何内容都不会被覆盖
- 合并时，使用**不同主密码**的设备绝不会覆盖已同步的 Vault，而是报告 Vault 不匹配并等待你明确选择
- 共用同一个同步保险柜的设备应保持相同的扩展版本；旧版本可能无法识别当前的封存格式，进而用旧副本覆盖记录

**说明**

- 同步面板会显示上次成功同步的时间、本地与云端账号数、浏览器同步配额的用量条（字节数和条目数）、待处理冲突以及暂停/错误状态。徽标显示"已暂停"时，表示需要按下方提示处理后才能继续同步。
- 同步会在弹窗打开（解锁后）以及其他设备修改数据时运行，没有"立即同步"按钮
- 关闭同步会保留云端副本供其他设备使用；在同一面板点击**删除同步数据**可将其从浏览器账号中移除。其他设备会保留本地账号，并在发现云端副本消失后关闭同步
- 同步开启期间不能关闭加密，因为明文记录永远不会被上传
- 授权密钥不会同步，每台设备需单独激活
- 数据由浏览器账号的同步服务（视浏览器为 Google 或 Microsoft）传输。账号名称和 TOTP 设置对该服务可读，密钥由 AES-GCM 和你的主密码封存。若希望传输本身也端到端加密，请开启浏览器的同步密码短语（Chrome：*同步和 Google 服务 → 加密选项*）
- 受浏览器同步配额限制（总量约 100 KB，单项 8 KB）；扩展会报告配额错误，而不是静默丢弃记录

### 导出与导入

**导出**

点击**导出**，选择两种格式之一：

- **加密备份** — 下载用 AES-GCM 256 加密的 `.lb2fa` 文件。备份密码由你在此处设置，与主密码相互独立，也是恢复该文件的唯一方式。备份文件自包含，即使主密码已修改或忘记，也能用它恢复账号。
- **明文** — 下载 `.txt` 文件，每行一个 `账号名称:Secret密钥`；若账号使用非默认的位数、周期或算法，则导出为 `账号名称:otpauth://…`。任何打开该文件的人都能读取，且不受主密码保护。

**导入**

点击**导入**，可选择：

- 明文 `.txt` 备份；
- 加密 `.lb2fa` 备份 —— 扩展会自动识别格式并询问备份密码；
- 包含 `otpauth://` 二维码、Google Authenticator 迁移二维码（`otpauth-migration://offline?data=…`）的图片或文件，或包含 Base32 密钥 / `otpauth://` 链接的文本。

已保存过的密钥会被跳过；HOTP 或不支持的条目会被跳过并计数。Google Authenticator 的多段导出请逐张图片导入；已导入的账号会自动跳过。

## 工作原理

1. 输入密钥，或粘贴一个 otpauth:// 链接。
2. 验证码用浏览器内置的加密能力在你的设备上算出。
3. 生成 6–8 位验证码并倒计时，到期自动刷新。
4. 点一下即可复制到剪贴板。

所有计算都在本地通过浏览器的 Web Crypto API 完成，生成验证码不会发起任何网络请求。只有在你明确开启加密跨设备同步后，已保存的数据才会离开设备。

## 隐私与权限

- **默认本地** — 保存的密钥存放在 `storage.local`，不开同步就不会离开设备
- **可选加密** — 未设置主密码时密钥为明文；开启后每条密钥都用 AES-GCM 256 封存，密钥由密码派生（PBKDF2-SHA256，60 万次迭代）且只存在于内存中
- **需主动开启的同步** — 只有你开启后，封存记录、账号名称、TOTP 设置以及 Vault 的盐/迭代次数/校验值才会写入 `storage.sync`，并由浏览器账号传输。主密码和授权密钥绝不包含在内
- **无分析追踪** — 不使用 Cookie、追踪、遥测或第三方脚本
- **无页面访问权限** — 没有内容脚本，不访问历史记录、标签页、书签或页面内容
- **最小化联网** — 未持有授权时，扩展不发起任何网络请求（唯一例外是重试此前在离线状态下排队的解绑）。持有授权时，扩展会联系 `api.annmax1983.com` 完成激活、复验（打开弹窗时每 2 小时最多一次）和解绑；这些请求携带授权密钥、随机生成的安装标识和浏览器元数据（浏览器名称/版本、语言列表、时区、User-Agent），绝不包含密钥或生成的验证码
- **最小权限** — 仅申请 `storage` 和 `clipboardWrite`，以及访问授权服务器域名的权限。`clipboardWrite` 用于复制验证码并在之后清空剪贴板，无法读取剪贴板内容，也不授予任何页面访问权限。同步不会新增权限，也不经过我们的服务器

逐字段的说明见 [privacy-policy.html](../privacy-policy.html)。

## ⚠️ 安全说明

- **加密是可选项** — 默认情况下，密钥以未加密形式存储在扩展的本地存储中，任何能访问你浏览器配置文件的人都可以读取。请在设置中开启主密码。
- **密码无法找回** — 主密码无法重置，加密记录没有密码就无法恢复。忘记密码时只能在锁屏界面清空记录重新开始。请提前导出备份；建议选择加密备份，并把备份密码单独保存 —— 备份密码同样无法找回。
- **移除扩展 = 本机数据丢失** — 卸载扩展或清除其本地数据会永久删除本机保存的所有账号。若同步已开启，浏览器账号中会保留一份副本，重新安装后重新激活授权、用同一主密码加入现有同步即可恢复；若希望彻底移除，请先点击**删除同步数据**。
- **同步不是备份** — 删除操作也会同步：在一台设备删除账号，其他设备也会删除。无法重新创建的账号请保留导出备份。
- **浏览器账号信任** — 同步数据由浏览器厂商的同步服务传输。密钥由主密码封存，但账号名称和 TOTP 设置不加密。同时能访问你的浏览器账号*和*主密码的人可以读取密钥；若希望传输本身也加密，请开启浏览器的同步密码短语。
- **导出格式不同，风险不同** — 明文 `.txt` 备份任何打开它的人都能读取，请当作机密文件保管，避免分享；加密 `.lb2fa` 备份用导出时设置的密码封存，该密码与主密码相互独立。
- **屏幕和剪贴板也会泄露** — 二维码需手动点击**显示二维码**；复制的验证码会在复制 30 秒后（或触发自动锁定时）从剪贴板清除；空闲自动锁定可缩短保险柜保持解锁的时间。弹窗关闭会销毁派生密钥，但关闭前刚复制的验证码会像普通复制一样留在系统剪贴板中。这些措施都无法保护一台已被入侵的电脑。
- **最佳实践** — 把密钥导入专用验证器 App 后，删除扩展中保存的那一份。
