## 为什么选择 LocalBox2FA？

大多数 2FA 验证器需要手机 App 或云端同步。LocalBox2FA 直接在浏览器中运行 — 不需要手机，不需要账号，数据永远不会离开你的设备。

| 优势 | 说明 |
|------|------|
| 🔒 **本地处理** | 所有 TOTP 计算在浏览器中通过 Web Crypto API 完成，密钥永不离机 |
| 📱 **不需要手机** | 直接在浏览器工具栏生成 2FA 验证码，无需手机 App |
| 🚫 **不需要账号** | 无需注册、云端同步或登录，安装即用 |
| ⚡ **极速生成** | 验证码生成不到 10ms，一键复制到剪贴板 |
| 🌙 **暗色模式** | 自动跟随系统暗色模式偏好 |
| 🎯 **极简轻量** | 无框架、无依赖、无臃肿。 |

## 安装方法

1. 打开浏览器扩展页面：
   - **Chrome**：`chrome://extensions/`
   - **Edge**：`edge://extensions/`
2. 开启右上角的**开发者模式**
3. 点击**加载已解压的扩展程序**，选择 `LocalBox2FA` 文件夹
4. 点击工具栏中的 🔐 LocalBox2FA 图标即可开始使用

---

## 使用方法

### 生成验证码

1. 点击工具栏中的 LocalBox2FA 图标
2. 将 TOTP Secret 密钥（Base32 格式）粘贴到输入框
3. 点击**生成** — 显示 6 位验证码和 30 秒倒计时
4. 点击**复制**将验证码复制到剪贴板

### 保存到记录

1. 生成验证码后，点击**保存**
2. 输入名称（如"GitHub"、"Google"）
3. 账号出现在历史记录列表中，实时显示验证码

### 使用已保存的账号

- 所有保存的账号实时显示验证码和倒计时
- 点击任意账号将其密钥加载到主显示区
- 每 30 秒自动刷新验证码

### 🔒 加密你的密钥

打开**设置（⚙）→ 主密码**，点击**开启加密**：

1. 设置主密码并确认
2. 已保存的密钥会立即被封存；此后列表中带 🔐 前缀
3. 下次打开弹窗时先看到锁屏，输入密码后才会显示验证码

注意：

- 主密码**无法重置或找回**。忘记后只能在锁屏界面清空全部记录重新开始，所以请保持一份导出的备份。
- 派生密钥只存在于内存中，弹窗一关就销毁 —— 这也是每次打开都要输密码的原因。
- 在同一面板点击**关闭加密**，会把所有记录解密回明文。

### 导出备份

- 点击**导出**下载所有保存的密钥为 `.txt` 文件
- 格式：`账号名称:Secret密钥`（每行一条）；若账号使用非默认的位数/周期/算法，则导出为 `账号名称:otpauth://…`
- 请妥善保管此文件 —— **它是明文的**，不受主密码保护

## 工作原理

```
输入 Secret 密钥（Base32）
       ↓
Web Crypto API 计算 HMAC-SHA1
       ↓
生成 6 位 TOTP 验证码（RFC 6238）
       ↓
30 秒倒计时 + 自动刷新
       ↓
一键复制到剪贴板
```

所有计算都在本地通过浏览器的 Web Crypto API 完成，密钥不会发起任何网络请求。

## 隐私保护

- ✅ **密钥留在设备上** — 所有 TOTP 计算在本地完成，保存的密钥永远不会离开浏览器
- ✅ **可选的静态加密** — 未设置主密码时密钥为明文；开启后每条密钥都用 AES-GCM 256 封存，密钥由密码派生（PBKDF2-SHA256，60 万次迭代）且只存在于内存中，从不写入存储
- ✅ **无分析追踪** — 不使用 Cookie、追踪或遥测
- ⚠️ **最小化且已披露的联网** — 免费功能**完全不发网络请求**。持有授权时，扩展会联系 `api.annmax1983.com` 完成激活、复验（打开弹窗时每 2 小时最多一次）和移除授权；这些请求携带授权密钥、随机生成的安装标识和浏览器元数据（浏览器名称/版本、语言列表、时区、User-Agent），**绝不包含你的密钥或生成的验证码**
- ✅ **最小权限** — 仅申请 `storage`（用于记住授权状态）和访问授权服务器域名的权限

## ⚠️ 安全说明

**使用前请仔细阅读：**

- **🔑 加密是可选项** — 默认情况下，密钥以**未加密**形式存储在浏览器扩展存储（`chrome.storage.local`）中，任何能访问你浏览器配置文件的人都可以查看所有已保存的密钥。请在设置中开启主密码加密。
- **🚫 密码无法找回** — 主密码无法重置，加密记录没有密码就无法恢复。忘记密码时，唯一的选择是在锁屏界面清空记录重新开始。请提前导出备份 —— 并妥善保管，因为备份文件是明文的。
- **💾 移除扩展 = 数据丢失** — 卸载扩展或清除其数据会**永久删除**所有已保存的账号。请提前导出备份文件。
- **📄 导出文件未加密** — 导出的 `.txt` 备份文件包含明文密钥，请妥善保管，避免公开分享。
- **🛡️ 最佳实践** — 将密钥转移到专用验证器应用后，删除扩展中保存的密钥。
