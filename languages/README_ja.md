TOTP 2FA 認証コードをローカルで生成する軽量ブラウザ拡張機能 — シークレットはすべてデバイス内に保存されます。

> Chromium ベース · Manifest V3 · ローカル処理 · プライバシー最優先

---

## なぜ LocalBox2FA？

ほとんどの 2FA 認証アプリはスマートフォンやクラウド同期が必要です。LocalBox2FA はブラウザ内で直接動作 — スマホ不要、アカウント不要、データがデバイスから離れることはありません。

| 利点 | 詳細 |
|------|------|
| 🔒 **完全ローカル** | すべての TOTP 計算は Web Crypto API を使用してブラウザ内で完結、鍵がデバイスの外に出ることはありません |
| 📱 **スマホ不要** | ブラウザのツールバーから直接 2FA コードを生成 |
| 🚫 **アカウント不要** | 登録不要、クラウド同期不要、インストールしてすぐ使用 |
| ⚡ **瞬時に生成** | コード生成は 10ms 未満、ワンクリックでクリップボードにコピー |
| 🌙 **ダークモード** | システムのダークモード設定に自動追従 |
| 🎯 **最小限** | フレームワークなし、依存関係なし、無駄なし。 |

## 互換性について

本拡張機能は RFC 6238 TOTP 標準に準拠し、Google Authenticator、Authy などの主流 2FA ツールが生成するシークレットキーをサポートします。本拡張機能は独立したツールであり、上記ブランドとは公式な提携関係はありません。

## インストール

1. ブラウザの拡張機能ページを開く：
   - **Chrome**: `chrome://extensions/`
   - **Edge**: `edge://extensions/`
2. 右上の**デベロッパーモード**を有効にする
3. **パッケージ化されていない拡張機能を読み込む**をクリックし、`local-box2-fa` フォルダを選択
4. ツールバーの 🔐 LocalBox2FA アイコンをクリックして開始

---

## 使い方

### コードを生成

1. ツールバーの LocalBox2FA アイコンをクリック
2. TOTP Secret キー（Base32 形式）を入力欄に貼り付け
3. **生成**をクリック — 6 桁のコードと 30 秒のカウントダウンが表示
4. **コピー**をクリックしてクリップボードにコピー

### 履歴に保存

1. コード生成後、**保存**をクリック
2. 名前を入力（例：「GitHub」「Google」）
3. アカウントが履歴リストに表示され、リアルタイムでコードを表示

### 保存済みアカウントの使用

- 保存したすべてのアカウントがリアルタイムでコードとカウントダウンを表示
- 任意のアカウントをクリックしてメイン表示に読み込み
- 30 秒ごとに自動更新

---

## 仕組み

```
Secret キーを入力（Base32）
       ↓
Web Crypto API が HMAC-SHA1 を計算
       ↓
6 桁の TOTP コードを生成（RFC 6238）
       ↓
30 秒カウントダウン + 自動更新
       ↓
ワンクリックでクリップボードにコピー
```

すべての計算はブラウザの Web Crypto API を使用してローカルで完結。シークレットがネットワークに送信されることはありません。

## プライバシー

- ✅ **シークレットはデバイス内に保持** — すべての TOTP 計算がローカルで完結、保存されたシークレットがブラウザの外に出ることはありません
- ✅ **分析・追跡なし** — Cookie、追跡、テレメトリは使用しません
- ✅ **ライセンス認証時のみ通信** — Premium ライセンスを認証する場合のみ、ライセンスキーと最小限のデバイス識別子がライセンスサーバーに送信されます。無料機能は完全にオフラインで動作し、ネットワークリクエストを行いません
- ✅ **最小限の権限のみ** — `storage`（ライセンス状態の記憶用）とライセンスサーバーへのアクセスのみ

## ⚠️ セキュリティに関する重要な注意

**ご使用前に必ずお読みください：**

- **🔑 平文保存** — シークレットキーはブラウザの `localStorage` に**暗号化されない**状態で保存されます。ブラウザプロファイルにアクセスできる人は全キーを閲覧できます。
- **💾 データ削除=データ消失** — ブラウザのキャッシュやサイトデータを削除すると、保存されたすべてのアカウントが**永久に消去**されます。事前にバックアップファイルをエクスポートしてください。
- **📄 エクスポートファイルは暗号化されていない** — エクスポートされた `.txt` ファイルには平文のシークレットキーが含まれます。安全に保管し、公開共有を避けてください。
- **🛡️ ベストプラクティス** — 専用の認証アプリにキーを移行した後、拡張機能に保存されたキーを削除してください。
