# LocalBox2FA

[English](../README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | 日本語 | [Français](README_fr.md)

TOTP 2FA認証コードを生成する軽量ブラウザ拡張機能です。秘密鍵の生成と保存はすべてデバイス上で完結します。

> Chromium系ブラウザ対応 · Manifest V3 · ローカル処理 · プライバシー最優先

## LocalBox2FAの特長

ほとんどの2FA認証アプリはスマートフォンのアプリやクラウド同期が必要です。LocalBox2FAはブラウザ上で直接動作します — スマートフォン不要、アカウント登録不要、秘密鍵がマシンの外に出ることはありません。

| 特長 | 詳細 |
|-----------|--------|
| 🔒 **ローカル処理のみ** | すべてのTOTP計算はWeb Crypto APIを使用してブラウザ内で実行されます。秘密鍵がデバイスの外に出ることはありません。 |
| 📱 **スマートフォン不要** | ブラウザツールバーから直接2FAコードを生成 — モバイルアプリは不要です。 |
| 🚫 **アカウント不要** | 登録もクラウド同期もログインも不要。インストールしてすぐに使えます。 |
| ⚡ **高速** | コードは10ms以内に生成。ワンクリックでクリップボードにコピー。 |
| 🌙 **ダークモード** | システムのダークモード設定に自動追従。 |
| 🎯 **ミニマル** | フレームワーク不使用、依存関係なし、無駄なコードなし。 |

## インストール

1. ブラウザの拡張機能ページを開きます：
   - **Chrome**: `chrome://extensions/`
   - **Edge**: `edge://extensions/`
2. **デベロッパーモード**を有効にします（右上のトグル）
3. **パッケージ化されていない拡張機能を読み込む**をクリックし、`LocalBox2FA`フォルダを選択します
4. ツールバーの🔐 LocalBox2FAアイコンをクリックして開始します

---

## 使い方

### コードを生成する

1. ツールバーのLocalBox2FAアイコンをクリックします
2. TOTP秘密鍵（Base32形式）を入力フィールドに貼り付けます
3. **生成**をクリック — 6桁のコードと30秒カウントダウンが表示されます
4. **コピー**をクリックしてコードをクリップボードにコピーします

### 履歴に保存する

1. コードを生成した後、**保存**をクリックします
2. 名前（例：「GitHub」「Google」）を入力します
3. アカウントが履歴リストにリアルタイムコード付きで表示されます

### 保存済みアカウントを使う

- 保存済みアカウントはすべてリアルタイムコードとカウントダウンタイマーを表示します
- 任意のアカウントをクリックして、そのコードをメイン表示に読み込みます
- コードは30秒ごとに自動更新されます

### 🔒 秘密鍵を暗号化する

**設定（⚙）→ マスターパスワード**を開き、**暗号化を有効にする**をクリックします：

1. マスターパスワードを設定して確認します
2. 保存済みの秘密鍵はその場で封印され、一覧に 🔐 が付きます
3. 次回ポップアップを開くとロック画面が表示され、パスワードを入力するまでコードは表示されません

注意：

- マスターパスワードは**リセットも復元もできません**。忘れた場合はロック画面から全データを消去してやり直すしかないため、エクスポートしたバックアップを保管してください。
- 派生鍵はメモリ上にのみ存在し、ポップアップを閉じると消えます — 毎回入力を求める理由がこれです。
- 同じパネルの**暗号化をオフにする**で、すべてのレコードを平文に戻せます。

### エクスポート＆バックアップ

- **エクスポート**をクリックして、保存済みのすべての秘密鍵を`.txt`ファイルとしてダウンロードします
- 形式：`アカウント名:秘密鍵`（1行に1つ）。桁数・周期・アルゴリズムが既定値以外の場合は `アカウント名:otpauth://…` になります
- このファイルは**平文**で、マスターパスワードでは保護されません。安全に保管してください

## 動作の仕組み

```
秘密鍵を入力（Base32）
       ↓
Web Crypto APIがHMAC-SHA1を計算
       ↓
6桁のTOTPコードを生成（RFC 6238）
       ↓
30秒カウントダウン＋自動更新
       ↓
ワンクリックでクリップボードにコピー
```

すべての計算はブラウザのWeb Crypto APIを使用してローカルで実行されます。秘密鍵がネットワークリクエストを発生させることはありません。

## プライバシー

LocalBox2FAはプライバシーを核となる原則として構築されています：

- ✅ **秘密鍵はデバイス上に保存** — すべてのTOTP計算はローカルで実行。保存された秘密鍵がブラウザの外に出ることはありません
- ✅ **任意の保存時暗号化** — マスターパスワード未設定時は平文。有効にするとすべての秘密鍵が AES-GCM 256 で封印され、鍵はパスワードから派生（PBKDF2-SHA256、60万回イテレーション）してメモリ上にのみ存在し、ストレージには決して書き込まれません
- ✅ **アナリティクスなし** — トラッキング、テレメトリ、Cookieなし
- ⚠️ **最小限かつ開示された通信** — 無料機能は**一切ネットワークリクエストを行いません**。ライセンスがある場合、拡張機能は `api.annmax1983.com` に接続して有効化・再検証（ポップアップを開いた際に2時間ごとに最大1回）・解除を行います。これらのリクエストにはライセンスキー、ランダム生成のインストール識別子、ブラウザのメタデータ（ブラウザ名/バージョン、言語リスト、タイムゾーン、User-Agent）が含まれますが、**秘密鍵と生成されたコードは含まれません**
- ✅ **最小限の権限** — `storage`（ライセンスステータスの記憶用）とライセンスサーバードメインへのアクセスのみ

## ⚠️ セキュリティに関する注意事項

**使用前に必ずお読みください：**

- **🔑 暗号化は任意** — 初期状態では秘密鍵はブラウザの拡張機能ストレージ（`chrome.storage.local`）に**暗号化なし**で保存され、ブラウザプロファイルにアクセスできる人はすべて閲覧できます。設定でマスターパスワードを有効にしてください。
- **🚫 パスワードの復元は不可** — マスターパスワードはリセットできず、暗号化されたレコードはパスワードなしでは復元できません。忘れた場合、ロック画面から全データを消去してやり直すしかありません。事前にバックアップをエクスポートし、そのファイル（平文）も安全に保管してください。
- **💾 拡張機能の削除＝データ損失** — 拡張機能をアンインストールまたはそのデータを消去すると、保存されたすべてのアカウントが**永久に消去**されます。事前にバックアップファイルをエクスポートしてください。
- **📄 エクスポートファイルは非暗号化** — エクスポートされた`.txt`バックアップには平文の秘密鍵が含まれます。安全に保管し、公開共有を避けてください。
- **🛡️ ベストプラクティス** — 専用の認証アプリに秘密鍵を転送した後、拡張機能から保存済みの秘密鍵を削除してください。
